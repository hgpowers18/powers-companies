# Powers Companies — Website

Marketing site for Powers Companies. The page is generated by [Eleventy](https://www.11ty.dev/)
from content files, and those content files are edited through a browser admin at `/admin`.

## Editing the site

Go to `https://<your-site>/admin` and choose **Sign In Using Access Token**. The prompt links
straight to GitHub's token page with the right permissions pre-selected; generate a token, paste
it in, and you're in. The token is stored in your browser, so this is a one-time step per device.

Saving writes a commit to this repository, which triggers a deploy. Changes are live in a minute
or two.

- **Site content** — every piece of copy and imagery on the page, grouped by section.
- **Developments** — the list of projects shown in the Developments section. It stays hidden
  until you add the first entry.

Images you upload land in `uploads/`.

## Structure

```
index.njk                    the page template
_data/site.yml               all copy and image paths
content/developments/*.md    one file per development
admin/                       the CMS (index.html + config.yml)
styles.css  main.js  uploads/
```

`_data/site.yml` and `admin/config.yml` mirror each other. If you add a field to one, add it to
the other or it won't be editable.

## Working locally

```bash
npm install
npm run dev      # http://localhost:8080 with live reload
npm run build    # writes _site/
```

Vercel runs `npm run build` and serves `_site`.

## What matches the design

- Exact colors, type (DM Sans / Hanken Grotesk / JetBrains Mono), spacing, breakpoints
- Sticky nav + mobile menu
- Hero carousel (6s autoplay, 1400ms crossfade)
- "Hear our story" audio with localStorage position
- Contact form success state (client-side only — wire a backend before launch)
